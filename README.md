# PlayMe
A web application for users to get information and summaries about their playlists and listening habits

## Languages and Packages
Developed using Python 3.14.7
TypeScript

fastapi,
uvicorn,
pandas,
requests,
python-multipart,
python-dotenv,
certifi

## Operating System and IDE
MacOS
Visual Studio Code

## Package Configuration

Open the project and run 

```bash
pip install -r needs.txt
``` 
If this does not properly download the packages, run pip install individually with each package

If pip not found command is present, use the following

```bash
python3 -m pip install
```

## Running the software

```bash
cd services
python3 cleanup.py
```
There is an example playlist .txt file in the services folder and used in cleanup.py
